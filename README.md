# 웹개발기초 10주차 실습

## 1. 프로젝트 소개
기존 영화 보드를 활용하여 JavaScript 객체 배열과 함수 6개를 학습한 실습입니다.

## 2. 사용 기술
- HTML
- CSS
- JavaScript
- GitHub Pages

## 3. 구현 기능
- 영화 5편의 정보를 객체 배열로 관리
- 영화 평균 평점 계산
- 최고 평점 영화 찾기
- 8점 이상 영화 필터링
- 평점 높은 순으로 영화 정렬
- 영화 개봉 후 경과 연도 계산
- TMDB 포스터 이미지 주소 생성
- 콘솔에 영화 정보 출력

## 4. 실행 결과
- 평균 평점: 7.7점
- 최고 평점 영화: 세븐
- 8점 이상 영화: 2편
- 영화 5편 정렬표 출력 완료
- 콘솔 오류 0개 확인
